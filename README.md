# Eolo Time - Desktop Weather Dashboard

![Versión](https://img.shields.io/badge/version-0.1.0-blue)

Una aplicación de escritorio moderna y elegante construida con Electron, Bootstrap y la API gratuita de OpenWeather.
En la versión actual se muestra el tiempo de Madrid, Barcelona, Bilbao y Sevilla, permitiendo seleccionar una de ellas para ver su pronóstico más en detalle.
