# Eolo Time - Desktop Weather Dashboard

![Versión](https://img.shields.io/badge/version-0.2.0-blue)

Una aplicación de escritorio moderna y elegante construida con Electron, Bootstrap y la API gratuita de OpenWeather.

En la versión actual se muestra de manera predeterminada el tiempo de Madrid, Barcelona, Bilbao y Sevilla, permitiendo seleccionar una de ellas para ver su pronóstico más en detalle. Además, permite añadir nuevas ciudades a los datos de guardado local para poder ver el pronóstico de otras ciudades según se desee.

Incluye otras funcionalidades como comprobar la Api Key guardada localmente y modificarla, reordenar las ciudades guardadas, así como eliminar las no deseadas, y cambiar el fondo entre cualquiera de las opciones dadas.
